# 급매 알림 이메일

## 사용자 입장

급매 Now! 탭 → 표 위 급매 줄의 **🔔 급매 알림** 버튼 → 팝업에서 켜고 저장.

- **로그인해야 신청할 수 있습니다.** 로그인하지 않고 누르면 로그인 안내가 뜨고,
  로그인하면 알림 창이 바로 열립니다.
- 저장되는 조건은 **그때 화면에 걸어 둔 필터 그대로**입니다 — 지역 핀(포함/제외),
  평형, 가격대, 급매 기준 %, 연식, 매매건수. 팝업에 요약이 보이니 확인하고 저장하세요.
- 발송 주기는 매일(새벽 수집 직후) 또는 주 1회(월요일) 중에 고릅니다.
- 받는 곳은 로그인한 구글 계정 이메일입니다.

조건을 바꾸고 싶으면 필터를 다시 맞춘 뒤 알림 창에서 저장하면 덮어씁니다.

## 관리자 입장

관리자 탭 → 사용자 관리 표에 **알림** 열이 있습니다.

| 표시 | 뜻 |
|---|---|
| 매일 / 주간 | 그 주기로 신청해 둔 상태 |
| 미신청 | 신청하지 않음 |
| 차단 | 관리자가 막아 둔 상태 |

**알림 차단 / 알림 허용** 버튼으로 사용자마다 끄고 켤 수 있습니다. 차단하면 그 사용자
화면의 알림 버튼이 "차단됨"으로 바뀌고 신청 자체가 잠기며, 발송 스크립트도 건너뜁니다.

차단 여부(`alertsAllowed`)는 보안 규칙에서 **관리자만** 바꿀 수 있도록 고정돼 있습니다.
사용자가 자기 문서를 고쳐 스스로 풀 수 없습니다.

## 실제로 메일이 나가려면 (한 번만 설정)

메일 발송은 `.github/workflows/send-bargain-alerts.yml` 이 자체 러너에서 돌립니다.
**아래 두 시크릿을 등록하기 전까지는 아무것도 보내지 않고 이유만 로그에 남깁니다.**

저장소 → Settings → Secrets and variables → Actions → New repository secret

| 이름 | 값 |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | Firebase 콘솔 → 프로젝트 설정 → 서비스 계정 → "새 비공개 키 생성"으로 받은 **JSON 파일 전체 내용** |
| `SMTP_URL` | `smtps://아이디@gmail.com:앱비밀번호@smtp.gmail.com:465` |
| `SMTP_FROM` | (선택) 보내는 사람 주소. 없으면 받는 사람 주소를 그대로 씁니다 |

앱 비밀번호에 `@ : / #` 같은 문자가 들어 있으면 퍼센트 인코딩해야 주소가 제대로 읽힙니다
(`@` → `%40`). 아이디의 `@`는 그대로 두어도 됩니다.

Gmail을 쓸 경우 계정 비밀번호가 아니라 **앱 비밀번호**가 필요합니다.
구글 계정 → 보안 → 2단계 인증을 켠 뒤 "앱 비밀번호"에서 발급받으세요.

### 먼저 확인만 해 보기

Actions → **Send bargain alerts** → Run workflow → `보내지 않고 대상만 확인` 을 켠 채 실행하면
메일을 보내지 않고 **받는 사람과 건수만** 로그에 찍습니다. 시크릿을 넣은 직후에 이걸로 한 번
확인하고 나서 실제 발송을 켜는 편이 안전합니다.

### 일정

기본은 UTC 21:00(KST 06:00)입니다. 새벽 2시에 시작하는 매물 수집이 끝난 뒤에 돌도록 잡았습니다.
수집이 길어져 겹치면 그날 메일은 이전 데이터 기준이 됩니다.

## 발송 대상 계산

메일에 담기는 목록은 화면의 급매 판정과 같은 규칙으로 고릅니다.

```
(실거래 최고가 - 최저 호가) / 실거래 최고가 >= 사용자가 저장한 급매 기준 %
```

- 실거래 최고가가 없는 행은 비교할 값이 없어 제외합니다.
- 같은 단지·같은 면적이 구 지역과 동 지역에 겹쳐 들어 있어도 한 번만 셉니다.
- 한 통에 최대 50줄까지 싣고, 나머지는 "이 밖에 N건이 더 있습니다"로 적습니다.
- 지역 핀이 하나도 없으면 보낼 대상이 없는 것으로 보고 건너뜁니다.

발송에 성공하면 그 사용자 문서에 `bargainAlert.lastSentAt` 과 `lastSentCount` 를 남깁니다.
